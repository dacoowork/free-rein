How the ink moves: each new drop pushes every existing point outward, p → c + (p−c)·√(1 + r²/|p−c|²), which keeps every area the same. A rake moves points along each tine by α·λ/(d+λ), where d is the distance to the tine, so ink nearest the teeth travels furthest.
